# 安裝與快速開始

本文涵蓋 Python 環境準備、執行測試，以及第一次的離線驗證。
完成後即可進入 [操作手冊.md](操作手冊.md)。

需求：**Python 3.11 以上**，唯一相依套件為 `PyYAML`。

## 安裝 Python

`py` 是 Windows 的 Python Launcher；WSL 是 Linux 環境，通常使用 `python3`
而不是 `py`。請依實際執行指令的終端機選擇。

### Windows PowerShell

1. 從 [Python 官方下載頁](https://www.python.org/downloads/windows/) 安裝 Python。
2. 安裝畫面勾選 **Add python.exe to PATH** 與 **Install launcher for all users**
   （或 **Install Python launcher**）。
3. 關閉並重新開啟 PowerShell，確認安裝：

   ```powershell
   py --version
   py -m pip --version
   ```

### WSL（Ubuntu／Debian）

```bash
sudo apt update
sudo apt install -y python3 python3-pip python3-venv
```

確認安裝：

```bash
python3 --version
python3 -m pip --version
```

若希望在 WSL 中以 `python` 代替 `python3`：

```bash
sudo apt install -y python-is-python3
```

## 安裝相依套件

```bash
python3 -m pip install PyYAML
```

或以 editable 模式安裝本專案（之後可直接使用 `oab-control` 指令）：

```bash
python3 -m pip install -e .
```

## 執行測試

在專案根目錄執行。全部 90 項測試應該通過。

**macOS／Linux（Bash）：**

```bash
PYTHONPATH=. python3 -m unittest discover -s tests -v
```

**Windows PowerShell：**

```powershell
$env:PYTHONPATH = "."
python -m unittest discover -s tests -v
```

PowerShell 不支援 `PYTHONPATH=. command` 這種 Bash 的行內環境變數語法，
必須先設定 `$env:PYTHONPATH`。若 Windows 未將 `python` 加入 PATH，
可改用 `py -m unittest discover -s tests -v`。

> 以下範例一律使用 Bash 語法。在 PowerShell 中請先設定 `$env:PYTHONPATH = "."`，
> 並移除每行開頭的 `PYTHONPATH=.`。

## 第一次離線驗證

這三個指令不需要 K3s、Discord 或 GitLab，可以立即執行。
它們使用 repository 內建的範例檔案。

**1. 驗證範例 catalog：**

```bash
PYTHONPATH=. python3 -m oab_control.cli validate examples/catalog.example.yaml \
  --no-path-check --secrets-file config/reference-manifest.example.yaml --json
```

預期輸出 `"valid": true`。`--no-path-check` 跳過本機路徑存在性檢查，
因為範例中的路徑不一定存在於你的機器上。

**2. 產生部署計畫：**

```bash
PYTHONPATH=. python3 -m oab_control.cli plan examples/catalog.example.yaml \
  --no-path-check --secrets-file config/reference-manifest.example.yaml
```

輸出是一份 JSON plan，包含每個 agent 的 workload、ServiceAccount、掛載點
與 NetworkPolicy 意圖。它明確標示 `"mutates_cluster": false`。

**3. 產生 OpenAB Helm values：**

```bash
PYTHONPATH=. python3 -m oab_control.cli render-openab examples/catalog.example.yaml \
  --no-path-check --secrets-file config/reference-manifest.example.yaml \
  > /tmp/openab-values.yaml
```

**4. 檢查預設環境合約：**

```bash
PYTHONPATH=. python3 -m oab_control.cli environment-validate config/environment.yaml --json
```

預期通過驗證，但狀態是 `bootstrap-pending` —— 這是刻意的。
加上 `--require-ready` 會失敗，直到操作員填妥所有 `pending_decisions`。

## 其他可用指令

```bash
PYTHONPATH=. python3 -m oab_control.cli --help
```

| 指令 | 用途 |
| --- | --- |
| `validate` / `normalize` | 驗證 catalog、輸出正規化 JSON |
| `plan` | 產生部署計畫（不變更系統） |
| `render-openab` / `render-k8s` | 產生 Helm values／Kubernetes 隔離資源 |
| `environment-validate` | 驗證環境合約 |
| `preflight` | 部署前唯讀檢查 |
| `backup` / `restore` | 外部備份與還原 |
| `deploy` / `status` / `rollback` | 部署、觀測、復原 |
| `task-*` | 任務紀錄的建立、轉換、報告、審查、列出 |
| `worktree-*` | Agent checkout 的建立、清理、退役 |

各指令的完整用法與閘門說明請見 [操作手冊.md](操作手冊.md)。

## 常見問題

| 症狀 | 處理 |
| --- | --- |
| PowerShell 顯示找不到 `PYTHONPATH=.` | 改用 `$env:PYTHONPATH = "."`，再執行命令 |
| WSL 顯示找不到 `py` | 這是正常的，WSL 請使用 `python3` |
| 終端機找不到 Python | 安裝後重新開啟終端機；Windows 先試 `py --version`，WSL 先試 `python3 --version` |
| `ModuleNotFoundError: oab_control` | 確認在專案根目錄執行，且已設定 `PYTHONPATH=.` |
| `ModuleNotFoundError: yaml` | 執行 `python3 -m pip install PyYAML` |
| `validate` 回報 `missing_path` | 範例 catalog 的路徑不存在於你的機器；加上 `--no-path-check` |
